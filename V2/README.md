# 📹 L.I.G.H.T — YouTube Video Intelligence Tool


Paste a YouTube link. Get a transcript, summary, detailed notes, and an AI chatbot — all in  **English, Hindi, or Nepali** .


## Features


* 🎙️ **Transcript** — YouTube captions or Gemini audio transcription (for videos with no subtitles)
* 📝 **Summary** — Easy / Medium / Hard complexity
* 📒 **Notes** — Detailed structured notes in Easy / Medium / Hard
* 💬 **Chat** — Video Chat (RAG), Web Search Chat, General Chat
* 🌐 **Multilingual** — English, Hindi, Nepali


## How to Use


1. Paste a YouTube URL in the sidebar
1. Enter your [Gemini API key](https://aistudio.google.com/api-keys) on the Home page
1. Generate transcript → then use Summary, Note, or Chat
